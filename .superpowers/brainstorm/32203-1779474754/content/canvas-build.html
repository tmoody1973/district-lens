Progress checklist at top. Cards appear below as each step completes. You see what the agent just did AND the data it found.

C — Think then Reveal

Canvas shows a "researching…" state while the agent works. When fully done, the complete brief appears all at once. Clean, but no live progress.

All three end up at the same place — a full race brief with candidates, finance, legislation, and positions. The difference is how much you see while the agent is working.
